    开发框架

    采用灵活的模块化设计，让您可以按需引入所需功能，避免不必要的开销。每个模块均经过精心打磨，可独立使用也可无缝协作。

    浏览开发框架文档

  • 🎨

    视图组件

    框架无关的 Headless UI 组件库，组件的状态机与无障碍逻辑沉在无头内核，Vue、React 与 Web Components 只是薄适配器；样式由设计令牌与纯 CSS 皮肤驱动，可整包替换。

    浏览视图组件文档

    基础应用

    提供完整的企业级应用构建方案，包括权限管理、工作流审批、代码生成等常用功能，助力企业快速构建安全、稳定、高效的业务系统。

    浏览基础应用文档

    高效快速跨平台

    后端由 .NET 驱动，执行速度快于任何其他常用框架，可以在多个平台运行。精心设计之功能、不断研磨之算法，在程序的高性能、高可用和高扩展性上夯实基础。

    了解 DotNet

    性能出色灵活多变

    前端由 Vue 驱动，经过编译器优化、完全响应式的渲染系统，几乎不需要手动优化。丰富的、可渐进式集成的生态系统，可以根据应用规模在库和框架间切换自如。
