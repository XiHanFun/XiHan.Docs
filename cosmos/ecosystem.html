生态总览 ​

曦寒不是一个仓库，而是三个可以独立使用、也可以叠起来用的开源项目。本页讲它们各自是什么、彼此什么关系、你的场景该从哪个进去。

三者各有独立的文档站，本站只负责生态层面的导览与共同的贡献约定。

三个仓库 ​

定位项目技术栈文档站
后端基座XiHan.Framework.NETframework.docs.xihanfun.com
前端基座XiHan.UITypeScript · Vue · React · Web Componentsui.docs.xihanfun.com
基础应用XiHan.BasicApp.NET + Vuebasicapp.docs.xihanfun.com

XiHan.Framework · 后端基座 ​

快速、轻量、高效、用心的 .NET 现代模块化开发框架。是面向企业级应用的模块化后端框架，框架优先使用 .NET 原生功能，减少第三方依赖，理念现代、开箱即用、模块清晰、依赖可控、扩展可维护。曦寒懿（XiHanFun）开源生态的后端基座。

按需引用的 NuGet 包，模块之间用 [DependsOn] 声明依赖，启动时自动拓扑排序装配。

XiHan.UI · 前端基座 ​

快速、轻量、高效、用心的框架无关 Headless UI 组件库。是面向企业级前端的设计系统运行时，无头内核，多框架适配器。提供基础组件与 AI 组件，覆盖从中后台到 AI 对话的界面构建场景。曦寒懿（XiHanFun）开源生态的前端基座。

XiHan.BasicApp · 基础应用 ​

基于 XiHan.Framework 和 XiHan.UI 的超高颜值通用中后台内核。开箱即用，提供 RBAC + 数据范围 + 字段脱敏的权限管理、多租户隔离、代码生成、实时通信、灰度发布、AI 等核心能力，满足新型企业级中后台管理场景。属于曦寒懿（XiHanFun）开源生态的基础应用。

彼此什么关系 ​

      ┌───────────────────────────────┐
      │        XiHan.BasicApp         │  企业级中后台，可直接投产
      │  后端 modules/  ·  前端 src/  │
      └───────┬───────────────┬───────┘
              │ 引用 NuGet    │ 引用 npm 包
      ┌───────▼───────┐  ┌────▼─────────────┐
      │ XiHan.Framework│  │   XiHan.UI      │
      │  .NET 模块包   │  │  设计系统运行时  │
      └───────────────┘  └─────────────────┘

两条依赖关系值得先说清楚：

  • BasicApp 的后端确实建立在 Framework 之上：它引用框架的 NuGet 包，认证、授权、数据访问、多租户、动态 API 等底层能力都来自框架，BasicApp 只写业务。想看框架能力在真实业务里怎么落地，读 BasicApp 的源码是最快的路径。
  • BasicApp 的前端同样建立在 UI 之上：自 BasicApp v4.0.0 起，前端整体用 XiHan.UI 重建，naive-ui 全量下线。想看组件库在真实业务里怎么用，读 BasicApp 前端的源码是最快的路径。

Framework 与 UI 之间没有依赖关系，一个是 .NET 后端包，一个是前端库，各自可以单独使用。

AI 辅助开发 ​

三个文档站都有「AI 辅助开发」一册：给 AI 编程工具的提示词与使用技能、MCP 服务端接入，以及可以直接放进上下文的 LLMs.txt。框架与组件库还各自随版本发布一个离线 CLI，同时也是 MCP 服务端：

项目工具在项目根接入文档
XiHan.Framework.NET 工具 XiHan.Framework.Cli，查包、模块类、配置节与文档dnx XiHan.Framework.Cli --yes -- setup --client claude开发框架 · For Agents
XiHan.UInpm 包 @xihan-ui/cli，查组件 API、示例、设计令牌与 design.mdnpx -y @xihan-ui/cli setup --client claude视图组件 · For Agents
XiHan.BasicApp不单独发包，后端与前端分别接入上面两个服务端在仓库根依次运行上面两条命令基础应用 · MCP Server

两个 CLI 的数据随包离线发布，与各自产品同号。setup 读出项目引用的版本，把钉住版本的 MCP 配置与使用技能写进项目，AI 工具查到的就是项目在用的那一版；--client 还可以换成 cursor、vscode 或 codex。

版本与发布 ​

三个仓库独立发版，版本号互不对齐：

  • Framework 发布到 NuGet，版本真源是 framework/props/version.props
  • BasicApp 随仓库发布，版本真源是 backend/props/version.props
  • UI 发布到 npm，全部公开包始终同一个版本号，版本真源是 ui/packages/*/*/package.json

三个产品站导航栏的末项显示该项目当前的版本号；本站「生态」菜单里的徽章显示各项目的发布阶段。
