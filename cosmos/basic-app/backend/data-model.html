数据模型 ​

数据表清单，按业务域分组（XiHan.BasicApp.Saas 与 XiHan.BasicApp.Workflow 两个模块；代码生成、AI 模块的表不在此列）。想知道某张表归谁管、某个功能落在哪张表，看这页。

实体基类、列约定、软删与索引规范见 实体基类；连接与初始化见 数据库配置。

命名速查 ​

约定值
表名前缀Sys_
命名风格snake_case
主键列Basic_Id（不是 Id）
多租户列Tenant_Id，全局记录 = 0
软删列Is_Deleted
分表后缀_{year}{month}{day} + SplitType.Month（按月，形如 _20260801）

身份与安全 ​

表实体说明
Sys_UserSysUser用户主体，Email 全平台唯一
Sys_User_SecuritySysUserSecurity一对一安全扩展：密码哈希、锁定、MFA、多端策略
Sys_User_SessionSysUserSession会话中心（多端控制、撤销）
Sys_User_SettingSysUserSetting用户 UI 偏好（按场景 + key 存 JSON）
Sys_User_StatisticsSysUserStatistics用户统计
Sys_User_Api_CredentialSysUserApiCredential开放接口个人凭证（AppKey + AppSecret 密文，Data Protection 可逆加密）
Sys_External_LoginSysExternalLogin第三方身份绑定
Sys_Password_HistorySysPasswordHistory历史密码（防重用）

→ 统一认证

Sys_Constraint_Rule / Sys_Constraint_Rule_Item—约束规则引擎（SSD / DSD / 互斥 / 基数…）
Sys_Session_RoleSysSessionRole会话角色映射

分表查询要带时间范围

物理表名形如 Sys_Access_Log_20260801，要走 SqlSugar 的分表 API 按时间定位，不能当普通表直接查。
